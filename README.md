## Overview

Aiko is a native macOS application by Sindre Sorhus that performs on-device speech transcription using OpenAI's Whisper model. Audio files, voice memos, and system audio recordings are transcribed completely locally without any data leaving the device, with support for over 50 languages and the ability to export transcripts as text or SRT subtitle files.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Aiko** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **On-Device** | 100% local processing using Whisper — no audio sent to any server |
| **50+ Languages** | Transcription support for over 50 spoken languages |
| **SRT Export** | Export transcriptions as SRT subtitle files for video use |
| **Voice Memo Import** | Direct import from Apple Voice Memos with one click |
